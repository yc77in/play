桌面端多模态AI交互应用 说明书

  项目简介
本项目是基于Python开发的桌面端多模态AI交互应用,采用插件化架构设计，可以快速替换角色、修改交互逻辑，适合作为桌面 AI 助手开发参考模板


  功能介绍
1.智能对话：基于大模型 API 实现角色化智能对话，可通过修改promote来改变对话风格与回复规则
2.情感交互：内置情感分析模块，根据对话内容动态调整角色状态与交互反馈
3.本地语音合成：接入本地语音模型，实现角色专属语音播报与口型动画同步
4.视觉感知：支持屏幕截图分析，可根据屏幕内容生成对应交互反馈
5.长期记忆：基于本地向量数据库，实现历史对话存储与上下文关联记忆
6.媒体联动：自动检测系统媒体播放状态，生成对应内容的角色反馈
7.随机互动事件：定时触发互动场景，提升交互体验
8.对话管理：支持历史记录查看与单条记录删除，可灵活管理对话数据

前期、美术资源准备：
需要提前准备四组图片（合计18张）和一张图标

第一组图片：Normal静止状态，分别命名为——normal1.png(普通心情状态）、normal2.png(高心情状态）、normal3.png(低心情状态）
		     (该组图片用于表示角色在不同心情值下的闭嘴静止状态，按当前心情分支使用对应图片。)
第二组图片：Thinking思考状态，分别命名为——thinking1.png(普通心情状态）、thinking2.png(高心情状态）、thinking3.png(低心情状态）
		     （该组图片是API调用前的思考动画，文本输入时触发，按当前心情分支使用对应图片。）
第三组图片：Speaking说话状态，大分支为——1_speaking普通、2_speaking高心情、3_speaking低心情，是说话循环动画，
							每大分支对应小分支的为——speaking1、speaking2、speaking3三帧
							（建议命名为1_speaking1,1_speaking2,1_speaking3,,,,,,,,,,）
							（逻辑是循环播放1-2-3-2-1，模拟张嘴说话，直到对话结束，可使用tts+wav进行口型对齐。)
							（如果想让角色眨眼同理，也可以使用GIF，不过会糊）
第四组图片：Drag拖拽状态，分别命名为——drag1.png(普通)、drag2.png(高心情)、drag3.png(低心情）
		     （鼠标拖拽状态，按住时播放拖拽帧，松开后返回拖拽前的状态）


 图标（ico）：打开在线png转ico网站：https://www.aconvert.com/cn/icon/png-to-ico/ 转换一张oc.ico出来。

一、文件准备
第一步：在你喜欢的位置创建一个文件夹。比如 D:\AI（建议在D盘等内存多的地方）
第二步：按照以下结构规划文件
D:\AI
├─ oc         主程序放的位置
├─ audio_cache  语言模型生成的语音会缓存到这里
├─ GPT-SoVITS   语言模型下载到这，b站有下载链接
├─ vector_db      向量记忆模型的缓存放在这，不手动创建它也能自动创建

D:\AI\oc
├─ oc.py          主程序
├─ run.bat       运行程序
├─ pack.bat      打包程序（可选）
├─ install.bat      依赖一键下载程序（可选）
├─ 所有图片包括图标          
├─ tts_plugin.py  插件：语音+口型同步（独立文件）
├─ vision_plugin.py   插件：屏幕监控（独立文件）
├─ memory_plugin.py  插件：向量记忆（独立文件）
└─ music_plugin.py   插件：音乐媒体嗅探（独立文件）

二、环境配置
Python版本：Python 3.10.11
虚拟环境：Anaconda oc_pet虚拟环境
支持系统：Windows 10、Windows 11

第一步：下载好anaconda并打开 Anaconda Prompt

第二步：在Anaconda Prompt输入以下命令，创建并激活环境：
conda create -n oc_pet python=3.10.11 -y
conda activate oc_pet
（如果有已经创建好的环境，请改成你自己的环境名。如果不确定环境名，可以先输入 conda env list 查看列表。）

第三步：确认 Python 版本正确。在Anaconda Prompt输入：
python --version
（屏幕上应该显示 Python 3.10.11 或者类似的 3.10.x 版本。）

第四步：在这个环境下，下载Spyder，这样方便看代码，这样下载得到的Spyder环境和conda一致，在Anaconda Prompt输入：
conda install spyder

第五步：启动Spyder，在Anaconda Prompt输入
Spyder

四、GPT-SoVITS的API调用方法:
1. 下载好GPT-VoVITS,找到go-webui.bat，训练生成一个专属语言的参考音频，命名为tts_output.wav，放在D:\AI\audio_cache下
（具体训练和推理看b站大佬的教程）
2.复制go-webui.bat，改名成api-webui.bat，
   把里面改成以下内容：
   runtime\python.exe api.py
   pause
3.按照api.py文件里面的说明配置好训练模型后保存api.py
4.运行api-webui.bat，打开浏览器输入127.0.0.1：9880
5.成功打开，运行项目前确保它在后台运行

六、其他可接入的插件（可以自行使用ai生成）
1、喂食与背包系统：请构建一个基于items.json的物品数据库，包含食物名称、图片路径和对应的回复文本。菜单点击“背包”展示网格列表，点击食物后，扣除数量，角色播放“进食”动画序列（如吃东西的GIF或两帧切换），并调用API根据食物名称生成一段口感评价。

2.实时语音通话：请整合VAD（静音检测）、Whisper（STT）和LLM。建立一个全双工或半双工的语音对话管道：按下快捷键说话 -> 录音停止 -> 转文字 -> 发送AI -> 播放语音。需要极极致的延迟优化，否则对话会非常卡顿。

3.多角色联动：(如果你打算做第二个oc ai) 请开放一个本地端口或共享文件。当桌面上同时开启了两个不同的桌宠进程时，让它们能够读取彼此的状态文件，从而实现两个OC在桌面上互相“对话”或“打闹”的效果。
